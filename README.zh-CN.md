# Cina-Claw Pro

Cina-Claw Pro 是一款面向 Windows 的自主多模态 AI 指挥中心，内置 OpenClaw。它将聊天、图像和文件、多代理协作、技能、浏览器工具、消息渠道及定时自动化整合在一个动画桌面界面中。

语音聊天使用 Windows 本机 `System.Speech`，无需付费语音服务。聊天输入框支持麦克风提示并可自动朗读助手回复；设置中提供 10 种调校风格（5 种女声、5 种男声），包含语速、声音深度、自动朗读和听写后发送。只有按下麦克风按钮后才会开始录音。

全新安装默认选择本地 Ollama `qwen3-vl:8b`，用于推理、图像输入及工具驱动的通用任务。请另行安装并启动 Ollama，然后运行 `ollama pull qwen3-vl:8b`。Cina-Claw Pro 不会静默切换到云端提供商。云端免费额度及模型可用性由外部提供商决定。凭据使用 Windows 系统加密保护。

规划、受限代码模式及多代理委派在首次启动时启用；未在允许列表中的主机命令需要确认。内置并启用 57 个经审查的技能：17 个来自 Anthropic 官方技能仓库，另有 40 个保留来源信息的 Cina 适配技能，覆盖所请求的研究、工程、浏览器、设计、网关、Google、VoltAgent、代理、媒体和工作流生态。适配技能不会静默安装外部运行时、启动服务、连接账户或授予机器访问权限；其他社区技能与插件仍需用户明确安装。

所有模型默认遵循真实、直接、基于证据、尽量少假设及保护隐私的行为规则，并尽可能完成合法且安全的请求；模型提供商与系统的强制规则仍然适用。密钥应通过安全设置输入，不要粘贴到聊天中。本机语音不会发送至语音服务，但发送给托管 AI 的聊天提示仍受该提供商隐私条款约束；需要本机推理时可使用 Ollama。
