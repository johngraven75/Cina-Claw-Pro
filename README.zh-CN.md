# Cina-Claw Pro

Cina-Claw Pro 是一款面向 Windows 的自主多模态 AI 指挥中心，内置 OpenClaw。它将聊天、图像和文件、多代理协作、技能、浏览器工具、消息渠道及定时自动化整合在一个动画桌面界面中。

语音聊天使用 Windows 本机 `System.Speech`，无需付费语音服务。聊天输入框支持麦克风提示并可自动朗读助手回复；设置中提供 10 种调校风格（5 种女声、5 种男声），包含语速、声音深度、自动朗读和听写后发送。只有按下麦克风按钮后才会开始录音。

全新安装默认选择本地 Ollama 模型 `qwen3-vl:8b-instruct`（Qwen3-VL 8B Instruct），并以 `qwen3-vl:4b-instruct` 和 `qwen3-vl:2b-instruct` 作为低显存回退。无需 API 密钥，但需要 Ollama 正在运行且模型已拉取一次；聊天界面会显示 Ollama 未运行 / 待拉取状态，并提供启动 Ollama 与拉取模型操作（及重新检查），而不会谎称已就绪。已退役的 OpenRouter `stealth/ox-alpha` 默认（返回 404）将永不再被预置。新配置的 OpenRouter 账户默认使用 `z-ai/glm-5.3-flash`，按量计费，并非免费预览，仅在用户添加 OpenRouter API 密钥后才会使用；Cina-Claw Pro 永远不会自动切换到付费模型。`openrouter/free` 仍可由用户明确选择。现有或升级安装中的提供商、模型和回退设置不会被替换。凭据由操作系统的安全存储保护；此共享配置适用于 Windows、macOS 和 Linux。

模型页面新增免费模型目录：50 个免费、开源、多模态推理模型（30 个标准模型加 20 个无审查模型），分为云端即用、一键拉取、进阶和不作为默认四组。OpenRouter 和 Ollama 行可直接应用到已启用的提供商账户；Hugging Face / vLLM / llama.cpp 行仅显示设置信息，不会假装已选择。所有目录模型都会预先挂接到各自的提供商，因此聊天打开时已默认选中 Ollama 模型，而非空白选择器。20 个无审查模型默认隐藏，需明确开启后才显示，仅限本地使用，永不作为默认。外部免费额度的可用性可能变化。新增行带有验证级别（强验证、仅存在性验证或仅片段验证）；仅片段验证的行未经验证可用。聊天页面还有 Manus 风格的任务视图：工具栏开关可打开任务标题栏，并在右侧分屏面板中显示步骤（实时计划步骤、工具调用和审批）、工作空间、预览和变更标签页。 人格页面：可编辑的灵魂（SOUL.md）、记忆（MEMORY.md）和系统提示词（AGENTS.md）空间，用于主智能体的工作区文件，通过文件服务保存（缺失时创建，创建时不覆盖），并在新会话中由 OpenClaw 读取。

聊天开关（按会话生效，位于模型选择器旁）：推理（含低/高/最高强度，仅为提示词指令而非提供商参数）、技能、文件 / 工作区、工具 / 代码执行、记忆、使用浏览器、网络搜索、深度研究、图像生成、语音 / 多模态输入、显示无审查模型，以及自主程度（关闭 / 监督 / 完全自主）。开关随每条提示词发送会话指令并限制输入框输入，不会改变全局运行时配置。已接线：技能（剥离标记）、文件（丢弃附件）、代码执行（关闭时自动拒绝，开启时保留允许列表和“未命中时询问”审批）、浏览器（抓取/导航加实际访问页面的活动列表）、无审查过滤（显式账户标记，名称标记仅作回退）。受限而非完整：网络搜索是会话级指令，但全局运行时配置中仍拒绝 `web_search`，因此搜索步骤会回退为对明确 URL 使用 `web_fetch` 并如实说明；深度研究同样受此限制，且只能列出实际抓取过的来源。未提供、也不宣称：没有实时浏览器视图（无法点击页面或在页面中输入，无实时预览），受限执行不等于完整沙箱，应用内提供 Ollama 启动和模型拉取操作（仅限预先连接的模型，仅限本地回环）。完全自主（有边界）：可在硬性边界内无人值守地继续执行多步任务，并提供完整活动日志和停止控件，并被指示绝不越界（这些边界由现有的审批卡片和 exec 允许列表/未命中时询问策略执行，而非由独立沙箱保证）：不删除工作区范围之外的文件，不重写历史，不提交或泄露密钥，不绕过或破坏审批、登录或删除保护，未经明确批准不发送消息、邮件或付款，不发布或发行，不扩大范围。危险操作会暂停等待批准；真正的阻塞会停止任务，而不是被绕过。

Cina Harness 层（草稿）：聊天、开关和任务视图与 Cina-Claw 自身的 Harness 核心对话，该核心负责会话编排、提供商/模型路由（预先挂接的目录默认值，拒绝已失效模型）、开关状态、工具路由、审批队列，以及带时间戳、仅含元数据的活动日志。底层的引擎是一个适配器：初始默认是现有的 OpenClaw 网关/ACP 引擎，它仍然提供会话、渠道、定时任务、技能执行和插件运行时，Harness 并不取代它。直连引擎（OpenAI 兼容的 Ollama/OpenRouter 聊天）已定义但在本草稿中只是存根：由于目前没有可用于 OpenAI 兼容聊天的主机路由，且渲染进程不得直接访问 Ollama 或网关，因此它暂不可用，绝不伪造回复，也绝不静默替代 OpenClaw。未来更换引擎只需新增一个适配器；界面、开关和目录无需改变。


规划、受限代码模式及多代理委派在首次启动时启用；未在允许列表中的主机命令需要确认。内置并启用 102 个经审查的技能：17 个来自 Anthropic 官方技能仓库，另有 85 个保留来源信息的 Cina 适配技能，覆盖所请求的研究、工程、浏览器、设计、网关、Google、VoltAgent、代理、媒体和工作流生态。适配技能不会静默安装外部运行时、启动服务、连接账户或授予机器访问权限；其他社区技能与插件仍需用户明确安装。

所有模型默认遵循真实、直接、基于证据、尽量少假设及保护隐私的行为规则，并尽可能完成合法且安全的请求；模型提供商与系统的强制规则仍然适用。密钥应通过安全设置输入，不要粘贴到聊天中。本机语音不会发送至语音服务，但发送给托管 AI 的聊天提示仍受该提供商隐私条款约束；需要本机推理时可使用 Ollama。
