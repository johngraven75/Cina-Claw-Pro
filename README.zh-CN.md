# Cina-Claw Pro

Cina-Claw Pro 是一款面向 Windows 的自主多模态 AI 指挥中心，内置 OpenClaw。它将聊天、图像和文件、多代理协作、技能、浏览器工具、消息渠道及定时自动化整合在一个动画桌面界面中。

默认提供 `openrouter/free`、Gemini `gemini-3-flash-preview` 和本地 Ollama `gemma4:latest`。免费额度及模型可用性由外部提供商决定。凭据使用 Windows 系统加密保护。

规划、受限代码模式及多代理委派在首次启动时启用；未在允许列表中的主机命令需要确认。内置 17 个官方 Anthropic 技能，社区技能与插件需由用户明确安装。

开发和发布命令请参阅英文 [README.md](README.md)。
