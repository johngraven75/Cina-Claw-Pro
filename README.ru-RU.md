# Cina-Claw Pro

Cina-Claw Pro — автономный мультимодальный центр управления ИИ для Windows со встроенной средой OpenClaw. В одном анимированном интерфейсе доступны чат, изображения и файлы, несколько агентов, навыки, браузер, каналы и расписания.

Голосовой чат использует встроенный Windows `System.Speech`, поэтому платный голосовой сервис не нужен. Доступны голосовой ввод, автоматическое озвучивание ответов и 10 настроенных профилей — 5 женских и 5 мужских — с регулировкой скорости, глубины, автоозвучивания и отправки после диктовки. Микрофон включается только после нажатия кнопки.

В новых установках и новых учётных записях OpenRouter по умолчанию выбирается `stealth/ox-alpha` (Ox Alpha). Сейчас это бесплатная скрытая предварительная модель с рассуждением, вызовом инструментов и мультимодальным вводом; доступность, цена, возможности и условия провайдера могут измениться. `openrouter/free` остаётся вариантом, который пользователь может выбрать явно. Настройки провайдера, модели и резервных моделей в существующих и обновлённых установках не заменяются. Учётные данные защищены безопасным хранилищем ОС, а общая конфигурация применяется в Windows, macOS и Linux.

Планирование, ограниченный режим кода и делегирование агентам включаются при первом запуске. Команды вне списка разрешений требуют подтверждения. В комплект входят и включены 57 проверенных навыков: 17 из официального репозитория Anthropic и 40 адаптеров Cina с сохранённым происхождением для запрошенных экосистем исследований, разработки, браузеров, дизайна, шлюзов, Google, VoltAgent, агентов, медиа и рабочих процессов. Адаптеры не устанавливают внешние среды, не запускают службы, не подключают учётные записи и не предоставляют доступ к компьютеру без явного действия; остальные сторонние расширения устанавливаются только явно.

Для всех моделей по умолчанию действуют правила правдивости, краткости, доказательности, минимума предположений, конфиденциальности и максимального выполнения законных и безопасных запросов. Обязательные правила системы и провайдера продолжают действовать. Секреты следует вводить через защищённые настройки, а не вставлять в чат. Локальная речь не передаётся голосовому сервису, но запросы к облачной AI-модели обрабатываются по условиям конфиденциальности её провайдера; для локального вывода можно использовать Ollama.

Команды разработки и выпуска приведены в английском [README.md](README.md).
