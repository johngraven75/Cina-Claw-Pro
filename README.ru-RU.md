# Cina-Claw Pro

Cina-Claw Pro — автономный мультимодальный центр управления ИИ для Windows со встроенной средой OpenClaw. В одном анимированном интерфейсе доступны чат, изображения и файлы, несколько агентов, навыки, браузер, каналы и расписания.

Голосовой чат использует встроенный Windows `System.Speech`, поэтому платный голосовой сервис не нужен. Доступны голосовой ввод, автоматическое озвучивание ответов и 10 настроенных профилей — 5 женских и 5 мужских — с регулировкой скорости, глубины, автоозвучивания и отправки после диктовки. Микрофон включается только после нажатия кнопки.

В новых установках по умолчанию выбирается локальная модель Ollama `qwen3-vl:8b-instruct` (Qwen3-VL 8B Instruct), с резервными вариантами `qwen3-vl:4b-instruct` и `qwen3-vl:2b-instruct` для меньшего объёма видеопамяти. Ключ API не нужен, но Ollama должна быть запущена, а модель загружена один раз; чат показывает статус «Ollama не запущена / модель не загружена» и действие повторной проверки, а не выдаёт готовность за действительную. Отозванное значение OpenRouter `stealth/ox-alpha` по умолчанию (404) больше никогда не задаётся. В новых учётных записях OpenRouter по умолчанию используется `z-ai/glm-5.3-flash` — с оплатой по факту использования, а не бесплатная предварительная версия; она применяется только если вы добавите API-ключ OpenRouter, а Cina-Claw Pro никогда автоматически не переключается на платную модель. `openrouter/free` остаётся вариантом, который пользователь может выбрать явно. Настройки провайдера, модели и резервных моделей в существующих и обновлённых установках не заменяются. Учётные данные защищены безопасным хранилищем ОС, а общая конфигурация применяется в Windows, macOS и Linux.

На странице моделей добавлен каталог бесплатных моделей: 50 бесплатных открытых мультимодальных моделей с рассуждением (30 стандартных и 20 без цензуры), разделённых на мгновенные облачные, one pull, продвинутые и не по умолчанию. Строки OpenRouter и Ollama можно применить к включённой учётной записи провайдера; строки Hugging Face / vLLM / llama.cpp только показывают настройку и не выдают её за выбор. Все модели каталога заранее прикреплены к своим провайдерам, поэтому чат открывается с уже выбранной моделью Ollama по умолчанию, а не с пустым выбором. Двадцать моделей без цензуры скрыты до явного включения, только для локального использования и никогда не по умолчанию. Доступность внешних бесплатных квот может меняться.  Новые строки имеют уровень проверки (сильный, только существование или только фрагмент); строки только с фрагментом не проверены как работающие. На странице чата также есть вид задачи в стиле Manus: переключатель на панели инструментов открывает заголовок задачи и разделённую панель со вкладками Шаги (живые шаги плана, вызовы инструментов и подтверждения), Рабочая область, Просмотр и Изменения. Страница «Персона»: редактируемые пространства Душа (SOUL.md), Память (MEMORY.md) и Системный промпт (AGENTS.md) для файлов рабочей папки главного агента; сохранение идёт через файловый сервис (создание при отсутствии, без перезаписи при создании), а OpenClaw читает их в новых сессиях.

Переключатели чата (в пределах сессии, рядом с выбором модели): рассуждение (глубина «низкая/высокая/максимальная» — это инструкция в промпте, а не параметр провайдера), навыки, файлы / рабочая папка, инструменты / выполнение кода, память, использование браузера, поиск в сети, глубокое исследование, генерация изображений, голосовой / мультимодальный ввод, показ моделей без цензуры и автономность (выкл. / под контролем / полная автономность). Переключатели отправляют инструкцию сессии с каждым промптом и ограничивают ввод в редакторе, но не меняют глобальную конфигурацию среды выполнения. Подключено: навыки (удаление токенов), файлы (отбрасывание вложений), выполнение кода (при отключении — автоматический отказ, при включении сохраняются allowlist и подтверждения при промахе), браузер (загрузка/переход плюс список активности фактически затронутых страниц), фильтр без цензуры (явный флаг учётной записи, маркеры имён — только запасной вариант). Ограничено, а не полно: поиск в сети — это инструкция уровня сессии, но `web_search` запрещён в глобальной конфигурации среды выполнения, поэтому шаги поиска переходят на `web_fetch` явных URL и сообщают об этом; глубокое исследование наследует это ограничение и должно перечислять только действительно загруженные источники. Недоступно и не заявляется: нет живого окна браузера (без нажатий на страницы и ввода в них, без живого предпросмотра), выполнение с ограничением области — это не полная песочница, а действий запуска Ollama или загрузки модели в приложении пока нет — только статус и повторная проверка. Полная автономность (ограниченная): продолжает многошаговые задачи без присмотра в жёстких границах, с полным журналом активности и кнопкой остановки, но никогда не пересекает жёсткие границы: не удаляет файлы вне области рабочей папки, не переписывает историю, не фиксирует и не раскрывает секреты, не обходит и не отменяет подтверждения, вход или защиту от удаления, не отправляет сообщения, письма или платежи и не публикует и не выпускает ничего без явного одобрения, не расширяет область. Опасные действия приостанавливаются для одобрения; настоящие блокеры останавливают задачу, а не обходятся.

Слой Cina Harness (черновик): чат, переключатели и вид задач обращаются к собственному ядру Harness в Cina-Claw, которое владеет оркестрацией сессий, маршрутизацией провайдеров/моделей (предварительно прикреплённые значения каталога по умолчанию, отозванные модели отклоняются), состоянием переключателей, маршрутизацией инструментов, очередью подтверждений и журналом активности с отметками времени, содержащим только метаданные. Движок под ним — это адаптер: начальный по умолчанию — существующий движок шлюза OpenClaw/ACP, который по-прежнему предоставляет сессии, каналы, cron, выполнение навыков и среду плагинов; Harness его не заменяет. Прямой движок (OpenAI-совместимый чат Ollama/OpenRouter) определён, но в этом черновике является заглушкой: он пока недоступен, поскольку нет хост-маршрута для OpenAI-совместимого чата, а процесс рендеринга не должен напрямую обращаться к Ollama или шлюзу, поэтому он никогда не подделывает ответы и никогда молча не подменяет OpenClaw. Будущая замена движка потребует лишь добавления адаптера; интерфейс, переключатели и каталог не изменятся.


Планирование, ограниченный режим кода и делегирование агентам включаются при первом запуске. Команды вне списка разрешений требуют подтверждения. В комплект входят и включены 102 проверенных навыка: 17 из официального репозитория Anthropic и 85 адаптеров Cina с сохранённым происхождением для запрошенных экосистем исследований, разработки, браузеров, дизайна, шлюзов, Google, VoltAgent, агентов, медиа и рабочих процессов. Адаптеры не устанавливают внешние среды, не запускают службы, не подключают учётные записи и не предоставляют доступ к компьютеру без явного действия; остальные сторонние расширения устанавливаются только явно.

Для всех моделей по умолчанию действуют правила правдивости, краткости, доказательности, минимума предположений, конфиденциальности и максимального выполнения законных и безопасных запросов. Обязательные правила системы и провайдера продолжают действовать. Секреты следует вводить через защищённые настройки, а не вставлять в чат. Локальная речь не передаётся голосовому сервису, но запросы к облачной AI-модели обрабатываются по условиям конфиденциальности её провайдера; для локального вывода можно использовать Ollama.

Команды разработки и выпуска приведены в английском [README.md](README.md).
