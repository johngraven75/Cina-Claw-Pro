# Cina-Claw Pro

Cina-Claw Pro — автономный мультимодальный центр управления ИИ для Windows со встроенной средой OpenClaw. В одном анимированном интерфейсе доступны чат, изображения и файлы, несколько агентов, навыки, браузер, каналы и расписания.

Предустановлены бесплатные варианты: `openrouter/free`, Gemini `gemini-3-flash-preview` и локальная Ollama `gemma4:latest`. Квоты и доступность моделей определяются внешними провайдерами. Учётные данные защищаются шифрованием Windows.

Планирование, ограниченный режим кода и делегирование агентам включаются при первом запуске. Команды вне списка разрешений требуют подтверждения. В комплект входят 17 официальных навыков Anthropic; сторонние расширения устанавливаются только явно.

Команды разработки и выпуска приведены в английском [README.md](README.md).
