# CinaCLAW v1.0.4 Promotional Package

This directory contains the finalized **60-second 16:9 CinaCLAW AI product promo** produced for the v1.0.4 Windows release. The package contains the rendered MP4, English male voiceover, shot blueprint, deterministic FFmpeg assembly script, checksum manifest, and the release-and-audit report used as the factual source.

The promo uses real Cina-Claw-Pro repository screenshots for all product-interface shots. Cinematic treatment is limited to crops, pans, zooms, overlays, and transitions; it does not redraw product controls or claim unsupported behavior. The public call to action is the [v1.0.4 GitHub Release](https://github.com/johngraven75/Cina-Claw-Pro/releases/tag/v1.0.4).

Run `sha256sum -c cinaclaw-v1.0.4-promo-sha256.txt` from this directory to validate the MP4 and WAV. The assembly script expects the repository's tracked screenshots under `resources/screenshot/en/` and the generated narration file alongside it.
