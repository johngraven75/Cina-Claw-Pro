# Cina-Claw Pro

Cina-Claw Pro は OpenClaw を内蔵した Windows 向け自律型マルチモーダル AI コマンドセンターです。チャット、画像とファイル、マルチエージェント、スキル、ブラウザー、チャネル、スケジュール自動化を一つのデスクトップ UI に統合します。

音声チャットは Windows ネイティブの `System.Speech` を使うため、有料音声サービスは不要です。マイクによるプロンプト入力とアシスタント返信の自動読み上げに対応し、設定には女性 5 種・男性 5 種の計 10 プロファイル、速度、声の深さ、自動読み上げ、音声入力後の送信があります。録音はマイクボタンを押したときだけ開始します。

新規インストールではローカルの Ollama モデル `qwen3-vl:8b-instruct`（Qwen3-VL 8B Instruct）を既定で選択し、`qwen3-vl:4b-instruct` と `qwen3-vl:2b-instruct` を低 VRAM 向けフォールバックとします。API キーは不要ですが、Ollama の実行とモデルの初回プルが必要です。チャットは準備完了と偽らず、Ollama 未実行／未プルのステータスと再確認操作を表示します。廃止された OpenRouter `stealth/ox-alpha` の既定（404）は二度とシードされません。新しく構成した OpenRouter アカウントでは `z-ai/glm-5.3-flash` を既定とします。これは従量課金制で、無料プレビューではありません。OpenRouter API キーを追加した場合にのみ使用され、Cina-Claw Pro が有料モデルへ自動的に切り替えることはありません。`openrouter/free` はユーザーが明示的に選べる選択肢として維持されます。既存またはアップグレード済み環境のプロバイダー、モデル、フォールバック設定は置き換えません。認証情報は OS の安全なストレージで保護され、この共有設定は Windows、macOS、Linux に適用されます。

モデルページに無料モデルカタログを追加しました。無料・オープン・マルチモーダル推論モデル50件（標準30件＋検閲なし20件）を、クラウド即用、ワンプル、パワーユーザー向け、既定にしないの4グループに分けています。OpenRouterとOllamaの行は、有効なプロバイダーアカウントに直接適用できます。Hugging Face / vLLM / llama.cppの行はセットアップ情報のみを表示し、選択済みと偽りません。すべてのカタログモデルは各プロバイダーに事前にアタッチされるため、チャットは空白のピッカーではなく、Ollama の既定がすでに選択された状態で開きます。検閲なしモデル20件は明示的なオプトインまで非表示で、ローカルのみ、既定になることはありません。外部の無料枠の可用性は変動します。新規行には検証レベル（強力、存在のみ、スニペットのみ）が付きます。スニペットのみの行は動作検証済みではありません。チャットページにはManus風のタスクビューもあり、ツールバーの切替でタスクヘッダーを開き、右側の分割パネルにステップ（ライブの計画ステップ、ツール呼び出し、承認）、ワークスペース、プレビュー、変更タブを表示します。 ペルソナページ：メインエージェントのワークスペースファイルであるソウル（SOUL.md）、メモリ（MEMORY.md）、システムプロンプト（AGENTS.md）を編集できるスペース。ファイルサービス経由で保存され（存在しない場合は作成し、作成時に上書きしない）、新しいセッションで OpenClaw に読み込まれます。

チャットスイッチ（セッション単位、モデルピッカー横）：推論（低／高／最大の強さはプロンプト指示でありプロバイダー設定ではない）、スキル、ファイル／ワークスペース、ツール／コード実行、メモリ、ブラウザーを使う、Web 検索、ディープリサーチ、画像生成、音声／マルチモーダル入力、検閲なしモデルの表示、自律性（オフ／監督付き／完全自律）。スイッチは各プロンプトとともにセッション指示を送り、コンポーザーの入力を制御しますが、グローバルなランタイム設定は変更しません。配線済み：スキル（トークン除去）、ファイル（添付破棄）、コード実行（オフで自動拒否、オンで許可リストと未ヒット時の承認を維持）、ブラウザー（取得／移動と実際に触れたページのアクティビティ一覧）、検閲なしフィルタ（明示的なアカウントフラグ、名前マーカーはフォールバック）。制限付きであり完全ではありません：Web 検索はセッション単位の指示ですが、グローバルなランタイム設定では `web_search` が拒否されているため、検索ステップは明示的な URL に対する `web_fetch` にフォールバックし、その旨を伝えます。ディープリサーチも同じ制限を受け、実際に取得した出典だけを挙げなければなりません。提供されておらず、主張もしません：ライブのブラウザービューポートはありません（ページのクリックや入力、ライブプレビューなし）、スコープ付き実行は完全なサンドボックスではありません。アプリ内の Ollama 起動やモデルプル操作はまだなく、ステータスと再確認のみです。完全自律（境界付き）：厳格な境界内でマルチステップのタスクを無人で継続し、完全なアクティビティログと停止コントロールを備えますが、決して境界を越えません。ワークスペース範囲外のファイル削除、履歴の書き換え、シークレットのコミットや公開、承認・サインイン・削除保護の迂回や無効化、明示的な承認なしのメッセージ・メール・支払いの送信や公開・リリース、スコープの拡大はしません。危険な操作は承認のために一時停止し、本物のブロッカーは回避されるのではなくタスクを停止させます。

Cina ハーネス層（ドラフト）：チャット、スイッチ、タスクビューは Cina-Claw 独自のハーネスコアと対話します。ハーネスコアはセッション編成、プロバイダー／モデルルーティング（事前アタッチされたカタログの既定値、廃止モデルの拒否）、スイッチ状態、ツールルーティング、承認キュー、タイムスタンプ付きのメタデータのみのアクティビティログを担います。下層のエンジンはアダプターです。初期の既定は既存の OpenClaw ゲートウェイ／ACP エンジンで、セッション、チャネル、cron、スキル実行、プラグインランタイムは引き続き OpenClaw が提供し、ハーネスが置き換えることはありません。ダイレクトエンジン（OpenAI 互換の Ollama／OpenRouter チャット）は定義済みですが、このドラフトではスタブです。OpenAI 互換チャット用のホストルートがなく、レンダラーが Ollama やゲートウェイに直接アクセスしてはならないため、まだ利用できず、返信を偽造することも、OpenClaw の代わりに暗黙に使われることもありません。将来のエンジン交換はアダプターの追加だけで済み、UI、スイッチ、カタログは変わりません。


計画、制限付きコードモード、マルチエージェント委任を初回起動時に有効化します。許可リスト外のコマンドには確認が必要です。レビュー済みスキル 57 個を同梱して有効化します。内訳は Anthropic 公式リポジトリの 17 個と、依頼された研究、エンジニアリング、ブラウザー、デザイン、ゲートウェイ、Google、VoltAgent、エージェント、メディア、ワークフローの各エコシステム向けに出典を保持した Cina アダプター 40 個です。アダプターが外部ランタイムの導入、サービスの起動、アカウント接続、マシンアクセスの付与を暗黙に行うことはありません。その他のコミュニティ機能は明示的な操作でのみ導入します。

すべてのモデルには、正直で直接的かつ根拠に基づき、不要な仮定を避けてプライバシーを守り、合法で安全な依頼を最大限完了する既定ルールが適用されます。モデル提供元とシステムの必須ルールは引き続き適用されます。秘密情報は安全な設定画面に入力し、チャットへ貼り付けないでください。ローカル音声は音声ホストに送られませんが、ホスト型 AI へ送るプロンプトはその提供元のプライバシー条件で処理されます。ローカル推論には Ollama を利用できます。
