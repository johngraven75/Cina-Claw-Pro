# Cina-Claw Pro

Cina-Claw Pro は OpenClaw を内蔵した Windows 向け自律型マルチモーダル AI コマンドセンターです。チャット、画像とファイル、マルチエージェント、スキル、ブラウザー、チャネル、スケジュール自動化を一つのデスクトップ UI に統合します。

既定の無料優先モデルは `openrouter/free`、Gemini `gemini-3-flash-preview`、ローカル Ollama `gemma4:latest` です。無料枠とモデルの在庫は外部プロバイダーに依存します。認証情報は Windows の OS 暗号化で保護されます。

計画、制限付きコードモード、マルチエージェント委任を初回起動時に有効化します。許可リスト外のコマンドには確認が必要です。公式 Anthropic スキル 17 個を同梱し、コミュニティ機能は明示的な操作でのみ導入します。
