## 1. Selection and licensing rules

Use this priority order:

1. Existing repository dependencies and user-provided licensed assets
2. User-owned paid source with a compatible license
3. Well-maintained open-source or free commercial-use option
4. Original implementation or generated asset with documented provenance
5. Placeholder only when no lawful final asset is available

For every non-trivial third-party source record:

- product and asset name;
- official source URL;
- version or download date;
- license and commercial-use status;
- attribution requirement;
- purchaser/account owner when paid;
- where it is used in the repository;
- replacement or fallback.

Never bypass paywalls, remove watermarks without entitlement, copy showcase code without its license, scrape proprietary libraries, or claim a purchase exists.
