# Awesome AI Tools Catalog

Use this repository as a discovery index, not proof that a product is current, safe, unbiased, or the best choice. Recommendations that may cost meaningful time or money require current independent verification.

## Search and shortlist

1. Run: `python3 scripts/search_catalog.py references/catalog.json "need and constraints" --limit 12`
2. Clarify the use case, platform, budget, data sensitivity, deployment preference, integration needs, and must-have constraints.
3. Build a small shortlist. Prefer an already installed first-party Codex capability when it fully meets the goal.
4. Verify each finalist against its current official site and documentation: availability, features, price, limits, privacy, data retention, security, licensing, and regional support.
5. Clearly separate catalog descriptions, verified facts, and inference. Include tradeoffs and explain why the recommendation fits.

## Trust boundaries

- The source includes affiliate and promotional links. Do not interpret ordering, editor labels, or inclusion as independent endorsement.
- Do not repeat stale model names, pricing, privacy claims, or marketing metrics without current verification.
- Do not install software, create accounts, start trials, connect data, submit content, or purchase a plan unless explicitly requested.
- Review permissions and data handling before recommending browser extensions, meeting recorders, voice cloning, autonomous agents, cloud APIs, or tools that ingest private documents.
- Require authorization and consent for recording, biometric or voice use, personal data, security testing, scraping, outreach, publishing, or automated actions.
- Never send secrets, proprietary code, health data, financial data, or personal records to a third-party service merely because it appears in the catalog.
